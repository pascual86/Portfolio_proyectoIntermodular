# Portfolio · Pascual Martín

Web personal sencilla hecha con HTML y CSS (sin JavaScript) para la actividad "Mi primer Sprint en solitario" de la UD1 de Proyecto Intermodular (1º DAW).

## Estructura

```
portfolio-pascual/
├── index.html      Inicio con presentación y botón de contacto
├── sobre-mi.html   Foto y biografía (HU-01)
├── contacto.html   Email, LinkedIn y GitHub (HU-02)
├── css/
│   └── style.css   Variables en :root, cabecera, secciones, pie y responsive
└── img/            Imágenes de perfil (provisionales en SVG)
```

## Historias de usuario del Sprint

- **HU-05**: cabecera con logo y menú, y pie de página con copyright, comunes a las tres páginas.
- **HU-01**: página "Sobre mí" con foto y biografía.
- **HU-02**: contacto con email y enlaces a LinkedIn y GitHub (botón en el inicio y enlace en el pie).

## Pendiente antes de entregar

- Sustituir `img/perfil.svg` e `img/sobre-mi.svg` por fotos reales.
- Cambiar `tu-email@ejemplo.com` y los enlaces genéricos de LinkedIn y GitHub por los reales.

## Cómo verla

Abrir `index.html` en el navegador. Los iconos se cargan desde Boxicons (requiere conexión).
